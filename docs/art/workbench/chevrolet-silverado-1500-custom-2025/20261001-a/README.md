# Chevrolet Silverado 1500 Custom (2025) art and factory record

- Game entry: one Standard vehicle only; no Neglected/Rusty variants were requested.
- Assumption: 2025 Chevrolet Silverado 1500 Custom, Crew Cab short bed, 4WD. The user supplied trim, year, paint and engine; cab/bed/drive were unspecified, so this common supported configuration was selected and retained in the plan/model data.
- Engine: 2.7L TurboMax turbocharged inline-four; Chevrolet lists 310 hp, 430 lb-ft (583 Nm) and an 8-speed automatic, and states TurboMax is standard on Custom.
- Factory mass is null because trim/configuration-specific curb weight was not verified. The playable mass of 2,200 kg, acceleration, speed and price (C 8,000) are arcade balance estimates. Race controls use the shared six-speed system.
- The 2D source is chevrolet-silverado-1500-custom-2025-2d.png. Its black paint is achromatic, so ordinary hue-based recoloring cannot identify its body. The optional native-image paintAreas polygons address this asset only; glass, tires, wheels, grille and lights remain unmasked.
- Raw nonzero-alpha extent includes faint stray pixels at [0,39,1774,822]. Runtime fit bounds use alpha >= 128: [7,166,1758,636]. All opaque artwork, roof antenna and complete tire edges remain inside this crop. The source PNG stays unchanged.

# Neglected used car sprites

Used-condition art uses the built-in OpenAI imagegen edit tool. For each sprite, the clean cutout was viewed and supplied as the pixel reference. Generated outputs retain the original transparent-background side-profile composition where possible; metadata bounds and tire hubs are measured on the output PNG pixels. This condition depicts a usable older owner car: dulled paint, dust and road grime, scratches, small dents, cloudy lighting lenses, dirty wheels, and minor rust flecks. It must remain recognizable as the same model and drivable. Rusty/battered condition is generated and tracked separately.

## Cartoon game-art conversions

The realistic used cutouts are retained in [`art/realistic/`](art/realistic/). The game sprite uses one built-in image edit per car with that exact realistic car image and [`sports-car-side-sprite-atlas.png`](art/style-reference/sports-car-side-sprite-atlas.png) as paired inputs. The atlas is a style reference only; its grid and background are never copied. Outputs are transparent side-view sprites with the same model silhouette, direction and painted hue, restyled with bold black contour lines, broad flat cel-shaded paint, simple highlights and simplified wheel detail. Neglected wear remains moderate: modest lower grime, a few short scratches and small dents, mildly cloudy lamps, dirty wheels, and only tiny local rust marks. Body panels stay painted.

The edit prompt for each conversion asked to “redraw this same [model] as a much flatter cartoon game sprite” and explicitly preserved the listed model identity and facing. It required broad cel-shaded paint blocks, simplified reflections and wheel shapes, moderate localized wear, two complete rolling wheels, true alpha, and no ground/shadow/glow or unpainted panels. The 2024 Wrangler retains its visible rear spare as a fixed accessory. Inputs and outputs are recorded in `expansion-used-metadata.json` and their completion markers; source vehicle reference URLs remain attached to each metadata record.
